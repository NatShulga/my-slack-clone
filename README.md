# Slack Chat with Next.js (Study Project)

A study project for learning full-stack development with Next.js.
Implements real-time chat using WebSockets (Socket.io).

## Tech Stack

| Technology                         | Purpose                                        |
| :--------------------------------- | :--------------------------------------------- |
| **Next.js 14+ (App Router)** | Core framework (both frontend and backend API) |
| **TypeScript**               | Strong typing                                  |
| **Tailwind CSS**             | Styling without writing CSS                    |
| **Socket.io**                | Real-time (WebSockets)                         |
| **Prisma ORM**               | Database interaction (SQLite)                  |
| **SQLite**                   | Lightweight embeddable database (serverless)   |
